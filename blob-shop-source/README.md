# Blob Shop

[Открыть игру](https://anotherrealityai.github.io/toon-games/blob-shop/) · [Исходники](https://github.com/anotherrealityai/toon-games/tree/main/blob-shop-source)

Небольшая мастерская мягких блобов: три заказа без таймера, два материала, ушки, рожки, уточки и звёздочки. Предметы и мягкое тело — 3D; клиентка с восемью позами и интерьер — 2D. Предметы изготовлены отдельно в Blender; игровая сцена собрана в Three.js.

## Как играть

- Переносите капсулы на блоба и отпускайте — материал впитается.
- Прикрепляйте детали в любой точке. Бросайте игрушки на блоба — они погрузятся внутрь. Вместимость — три игрушки.
- Тяните, чтобы мять. Удерживайте неподвижно около половины секунды, затем двигайте палец или мышь, чтобы перевернуть.
- Быстро потяните за край, чтобы перенести целиком в корзинку. Отпустите и позвоните в колокольчик.
- Лишний предмет можно выбрать и вытянуть. Неверный заказ остаётся для исправления.

Обновление страницы начинает с первого заказа. После трёх доступен повтор.

## Запуск исходников

Node.js 22.12+.

```sh
npm ci
npm run dev
npm test
npm run build
```

Dev-сервер: `http://127.0.0.1:5282/`. Публикуемая сборка находится в `dist/`; Vite использует относительные пути. В runtime все модели, изображения и шрифт локальные. `?qa` включает диагностические данные без кнопок автосборки.

`src/` содержит приложение и физический адаптер; `assets/` — игровые ассеты; `blender/source/props/` — десять `.blend`; `blender/scripts/` — их воспроизводимую генерацию и проверки; `tests/` — тесты состава и физики. Nunito распространяется под лицензией в `assets/fonts/OFL.txt`.

Это первая тестовая сборка. Проверки логики и физики автоматизированы; интерактивный браузерный проход и визуальная приёмка сцены ещё не подтверждены. Производительность и управление на реальном телефоне требуют проверки. Поглощение игрушек — управляемая анимация с контактным откликом; физика жидкости не моделируется. При сильной тяге у корзины применяется дополнительная коррекция видимой оболочки.
