# Приложение Blob Shop 0.2

19 октября2026. Three.js/Vite, собственные GLB/PNG/Nunito. Сборка гибридная, без импорта общего Blender BLOCKOUT.

Центр экрана занят блобом и увеличенным ковриком. Добавки находятся в двух боковых лотках, звонок — справа внизу. Ортографическая камера сохраняет размеры целей при изменении высоты окна. Игровой контейнер ограничен шириной min(100%,590px,72dvh). Лицо поднято на видимую поверхность, глаза крупнее и круглее, улыбка шире. Крепления лица остаются физическими anchors.

По новому решению пользователя корзина удалена из сцены и из загрузки runtime. Выдача проверяется звонком на рабочем месте. Перенос целиком и trackball/long-hold удалены из обработчиков ввода. Любое удержание тела остаётся локальной физической тягой. Поворот возникает через движение частиц; рендерная group не используется для подмены физики.

Клиентка остаётся неподвижным idle-кадром. `customer.update` не вызывается. Смена заказа и ошибки показаны текстом/звуком; временная пауза анимации не удаляет исходный атлас.

Игрушки в теле были плохо читаемы через transmission-материал. Для этой версии применена alpha-полупрозрачность .48 без рефракции, отключено получение игрушками непрозрачной тени оболочки; слоты подняты выше лица. Размер моделей не меняется при поглощении. Это управляемая траектория, не жидкостная симуляция.

Единственное состояние состава — `Assembly`: pending/inside/attached/extracting, три резервируемых места, pendingMaterial и последовательность капсул. Для завершения извлечения требуется движение >.55U и полный выход world AABB предмета за тело. Извлечённый предмет опускается на стол с ограничением реальными границами и не возвращается под тело из-за старого узкого Z-clamp. Его можно снова взять и добавить тем же id.

Pointercancel/lost capture/blur/resize/visibility и второй указатель снимают текущий жест. Отмена извлечения восстанавливает только выбранный экземпляр. Reload начинает первый заказ. После трёх — повтор. Колокольчик не может повторно засчитать тот же заказ и ждёт окончания поглощения.

Проверены все три заказа мышью в браузере при412×915 и повторно production при360×740. Проверены ошибочный состав/материал, возврат конкретной игрушки, четвёртая игрушка, ранний и повторный звонок, долгий захват1200ms без смены режима, физическая тяга, help/replay/sound toggle. Клиентка: два crop-снимка до/после заказов побайтово совпали. Production-консоль:0 ошибок/предупреждений. Визуальные размеры также1280×800 и590×650. Это не тест реального телефона, touch, субъективного звука или FPS.

Подробные доказательства: `qa/app/browser/verification.json`, PNG рядом, `qa/app/projected-layout.json`, `qa/app/extraction-geometry.json`. Диагностика `?qa` только читает состояние, без автосборки/зачёта.
