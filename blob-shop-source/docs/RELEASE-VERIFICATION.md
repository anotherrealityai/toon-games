# Приёмка Blob Shop 0.2 — 19 октября2026

## Подтверждено

- 13 тестов состава и12 групп физики: exit0. Новый сценарий свободной рабочей зоны подтверждает поворот поверхности от локальных сил примерно на38.75°; рендерная группа остаётся с единичным quaternion. Материалы меняют реальные stiffness/pressure/damping того же тела.
- Все три заказа пройдены обычными мышиными действиями через Browser Use при412×915. После финальной сборки полный проход повторён при360×740 в production preview, без Vite HMR и без методов подстановки заказов.
- Проверены: лишний рожок → ошибка → снятие только этого предмета → приём; смена материала с сохранением id добавок; ранний звонок во время капсулы; неверный материал; четвёртая игрушка; короткий жест внутри; полное извлечение выбранной уточки и возврат того же id; повторный звонок; повтор игры.
- Удержание1200ms (фактически1546ms в инструменте) осталось режимом pull, не включало перенос/поворот целиком. Обычная тяга меняла физическую форму/ориентацию; состав сохранился.
- Два crop-снимка клиентки до и после заказов совпали побайтово: она статична. Help содержит новые правила, sound toggle меняет состояние/подпись.
- Production-консоль:0 ошибок и0 предупреждений. Предыдущие PMREM/PCFSoftShadowMap предупреждения устранены. У Vite остаётся build-предупреждение о JS chunk >500kB (~661kB до gzip); это не runtime-ошибка.
- Визуально осмотрены360×740,412×915,1280×800,590×650. Блоб расположен примерно на51–52% высоты, по горизонтальному центру. Минимальные расстояния целей:51.239/58.640/81.982/66.610px соответственно. 44px зоны помещаются. Ортографическая камера и два боковых лотка освобождают центр.
