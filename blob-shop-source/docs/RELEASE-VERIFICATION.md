# Приёмка Blob Shop0.3 — 19 октября2026

14 тестов состава,12 групп регрессии физики и5 новых групп материала/захватов/глаз прошли с exit0. `npm run build` успешен; сохраняется предупреждение Vite о JS chunk >500kB. Runtime-консоль:0 ошибок и0 предупреждений.

## Изменения и проверки

- Встроенное лицо удалено. Каждый глазик добавляется, учитывается и снимается отдельно; две установленные модели моргают и переводят взгляд. Проверены извлечение `item-1` и возврат того же id, сохранение другого глаза/ушей/уточки. Новый заказ начинается без лица.
- «Кокос» — третий полноценный материал. При замене сохраняются тело, топология, физические крепления и состав. Неверный материал отклонён звонком; после возврата Аквы заказ принят.
- Два захвата имеют собственные18 частиц и pointerId. Тесты проверяют сжатие, независимое движение, отпускание одного пальца, перекрывающиеся захваты, reset/cancel, замену материала во время удержания и конечность/объём/границы.
- В испытании одинакового растяжения на.25s RMS изменения формы Аквы=.2980U, Кокоса=.0642U. После3s работы и3s отдыха остаётся35.96% и68.38% достигнутой деформации соответственно. Мера использует попарные расстояния частиц и исключает перенос/поворот. Это результат данного сценария, не универсальный процент.
- Три обновлённых заказа пройдены мышью в production preview при360×740; контрольный проход повторён в обычном режиме без QA. Финальная выдача второго прохода сделана после проверки адаптации окна.
- Визуально осмотрены360×740,412×915,590×650,1280×800. Карточка из шести компонентов на телефоне имеет два ряда; на широком экране — один. Верхние добавки доступны. Минимальные расстояния между центрами целей:52.774/60.396/68.606/84.438px в соответствующих viewport из геометрического отчёта.
- Два новых предмета отдельно созданы в Blender: eye и capsule-coconut. Сохранены исходники, GLB, рендеры; структурная проверка всего набора прошла (12 канонических моделей,13 GLB,12 runtime GLB).
